The platform layer

The platform abstraction layer (PAL) is the compiler's internal contract with the host operating system. The Z98 side is sf/src/pal.zig; the C side is sf/src/include/zig_pal.c. The compiler's Z98 sources reach the OS only through the extern "c" declarations that sit between the two, so every host-specific call is isolated in this one layer.

The PAL is not part of the Z98 language. No pal symbol is reachable from user code unless a program declares its own extern prototypes. Z98 programs use the standard library instead; see Volume II, The standard library tour and the Volume IV standard library page (planned). This page is a compiler contributor's lookup.

Documented subset

The tables below list the callable public surface of sf/src/pal.zig: every pub fn and every pub const, followed by the C functions in zig_pal.c that implement them. Three things are deliberately out of scope, and the page states them rather than inventing a symbol:

  • The debug marker channel markerWrite, markerWriteInt, and markerWriteInt64 is compiled off (g_markers_debug = 0, so the functions emit nothing). The live measurement markers are the subject of the markers page (planned).
  • The private const values and the libc extern "c" bindings (fopen, fread, fwrite, fclose, fseek, ftell, c_exit) are implementation details of the public functions, not a callable surface of their own.
  • Categories a PAL often owns but the compiler PAL does not: memory is the arena allocator (sf/src/allocator.zig), console is the two stream functions below, platform detection is the language builtin @isWindows() (see Builtins), and time and sleep belong to std.time and std.io.sleepMs, not to the compiler PAL.

Streaming stdio

These wrap C stdio (fopen/fread/fwrite/fclose/ fseek) for the LIR spill store. They are strict: a short read, a short write, or a failed seek is fatal and reports through panic.zig.

Function Signature Returns / error Purpose
streamOpen pub fn streamOpen(path: []const u8, mode: [*]const u8) ?*void ?*void; null on a too-long path or a failed fopen Open a C stdio stream by mode string.
streamClose pub fn streamClose(file: *void) void void Close a C stdio stream.
streamWrite pub fn streamWrite(file: *void, buf: []const u8) void void; a short write panics (pal.zig:147) Write all of buf to the stream.
streamRead pub fn streamRead(file: *void, buf: []u8) void void; a short read panics (pal.zig:157) Fill all of buf from the stream.
streamSeek pub fn streamSeek(file: *void, offset: i32) void void; a nonzero fseek result panics (pal.zig:166) Seek to absolute offset.

The C side

sf/src/include/zig_pal.c implements the functions above and is linked into every emitted program. PlatFile is void* on _WIN32 and int elsewhere; PLAT_INVALID_FILE is (void*)-1 or -1 accordingly. The TrapContext struct is ten unsigned int fields (eip, esp, ebp, eflags, eax, ebx, ecx, edx, esi, edi) and mirrors std.debug.TrapContext.

pal_dir_exists int pal_dir_exists(const char* path) Nonzero when path is a directory.
