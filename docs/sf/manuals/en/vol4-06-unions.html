Unions

A union overlaps its members on one storage instead of giving each its own bytes. Z98 has three forms: the bare union (union { ... }, the C union), the packed union (packed union { ... }, bit-overlaid storage), and the tagged union (union(enum) { ... }, a compiler-managed tag beside a payload). This page is the lookup for the declaration syntax and member shapes, the layout rules, the synthetic .tag field and its member sugar, payload access and the whole-union reassignment idiom, the payload-store rejects, the packed-union member gate, and the print forms.

The authority is the parser (parserParseUnionType at sf/src/parser.zig:1427-1481), the tag/payload registration (sf/src/symbol_registrator.zig:148-197, tag type fixed at TYPE_U32 at :177), the packed-union layout (sf/src/type_registry.zig:1120-1177), the .tag sugar (sf/src/semantic_analyzer.zig:2314-2456, switch condition at :4288), the payload-store rejects (sf/src/lower.zig:2421 and :2926), and the print validator (printFmtAggFieldsOk at sf/src/lower.zig:1470-1514, printFmtCheck at :1528). Every rule below was reproduced on the fixed compiler (md5 7fc608358f4f6af5abab43e633d44f83); the reused fixture or sample is named where one exists.

Declaration syntax and the three forms

A union declaration is an ordinary const whose value denotes a type. Members are comma-separated field declarations; a trailing comma is optional. The form is chosen by what follows union. 

const Bits = union { f: f32, u: u32 };             // bare union
const Flags = packed union { whole: u8, lo: u4 };  // packed union
const Shape = union(enum) {                        // tagged union
    circle: i32,
    empty,
    box: struct { w: i32, h: i32 },
};
Form Spelling Meaning
bare const U = union { field: T, ... }; The C union: one storage, the program tracks the live member.
packed const U = packed union { field: uN, ... }; Members overlap at bit offset 0, no padding.
tagged const U = union(enum) { field: T, ... }; The compiler stores a u32 tag naming the live variant.

A tagged union is not a packed union: writing packed union(enum) is rejected at parse time. Level-0 error[2000] packed unions cannot be tagged (union(enum)); packed union is an untagged container is reported at the (enum), followed by a second error[2000] unexpected token at the brace.

Naked versus payload members

A member may carry a payload type (name: T) or be written as a bare name (name,). The bare-name form is naked-tag sugar: it is admitted only in a tagged union and is treated as an explicit void payload. In a bare union a bare member is accepted as a plain void field (not a tag); in a struct it is a parse reject.

Member spelling Tagged union Bare union Struct
name: T A variant with payload type T. A field of type T. A field of type T.
name: void A variant with an explicit void payload. A void field. A void field (measurable; not printable).
name, Naked tag: shorthand for name: void. Accepted as a void field; the type still has no tag. error[2000] struct fields must be all named or all positional (tuple).

A variant payload may be an anonymous struct written in place (box: struct { w: i32, h: i32 }); the compiler declares the internal struct. Payload reads reach its fields directly: s.box.w. The reused sample docs/sf/manuals/src/vol2/variant.z98 declares all three forms, the naked empty tag, and the anonymous box payload.

Layout

The frozen 32-bit model applies to all three forms. A bare union is the size of its largest member, rounded up to the largest member alignment. A tagged union is the u32 tag plus a payload union wide enough for the largest variant, laid out as a struct pair. A packed union is measured in bits.

Type (measure) Form @sizeOf / @alignOf / @bitSizeOf
Bits { f: f32, u: u32 } bare 4 / 4 / 32
union { i: i32, u: u32 } bare 4 / 4 / 32
union(enum) { a: i32, b: u32 } tagged 8 / 4 / 64 (tag 4 + payload 4)
union(enum) { a, b, c } (all naked) tagged 4 / 4 / 32 (the tag only)
union(enum) { a: i32, b: void } tagged 8 / 4 / 64
Shape { circle: i32, empty, box: struct { w: i32, h: i32 } } tagged 12 / 4 / 96 (tag 4 + 8-byte payload + pad)
packed union { a: u4, b: u12 } packed 2 / 1 / 12 (widest member)
packed union { x: bool, y: u1 } packed 1 / 1 / 1
packed union { a: u8, s: Inner }, Inner = packed struct { p: u4, q: u4 } packed 1 / 1 / 8 (the packed-struct member is 8 bits)

A union embedded in a struct participates in the outer layout normally. The reused fixture repro/mi_matrix/sizeof_struct_union_xmod holds a bare union { I: i64, S: []const u8, F: f64 } in a struct and measures the struct as 16 / 8 (reproduced as 24 when size and align are summed). @offsetOf/@bitOffsetOf reject a union target: level-0 error[3072] expected struct type, found 'Raw' (the type name varies); the reused repro repro/union_offset_reject.z98 pins three error[3072] rows for a bare union, a tagged union, and a packed union. Put the union in a struct and ask for the struct field's offset instead.

Packed-union member rules

Packed members overlap at bit offset 0, packed LSB-first, with no padding. A member is admitted only if it is bool, an integer of at most 31 bits, or a packed struct whose inner total width is the member's width (the ≤31-bit cap applies to the bool/integer leaves). The type's total bits are the widest member; @sizeOf is max(1, (total_bits + 7) / 8) and @alignOf is 1. 

const U = packed union { a: u4, b: u12 };
var u: U = .{ .b = 3000 };
// @sizeOf(U) is 2; u.a reads the low 4 bits: 3000 & 0xF = 8
Member written Code Message (measured)
an integer wider than 31 bits (u32, i64) error[3000] packed union field width must be <= 31 bits (u32/i64 etc. packed fields are not supported yet)
f32/f64, a pointer, or any non-integer error[3000] packed union fields must be bool or an integer type (uN/iN); this field type is not allowed in a packed union

A whole-member move of a packed-struct member (flags.halves = h, a whole-value read var c: Inner = u.b;, or a struct-literal element) lowers per leaf: one scalar bitfield load or store per leaf with composed offsets. The reused fixtures repro/mi_matrix/packed_union_xmod (prints 2 8) and repro/mi_matrix/packed_union_struct_wholemember_xmod (prints 2 3) pin the overlap and the per-leaf copy. The per-leaf recursion is bounded at 32 packed levels (lowerPackedWholeCopy, sf/src/lower.zig:2674); a deeper whole-value move is a clean level-0 error[3000], never a bad store.

Tagged unions: members and payload access

Construction names the variant and supplies its payload: .{ .circle = 2 }, .{ .box = .{ .w = 3, .h = 4 } }, or the naked .empty. A payload is read through the variant name (s.circle, s.box.w), and a whole tagged union is compared against a variant (s == Shape.circle, s == .empty). The reused sample src/vol2/variant.z98 prints circle tag=0 area=12, box tag=2 area=12 name=box, and empty tag=1 area=0 eq=true. The tag ordinal is the variant's declaration order, starting at 0.

The supported way to change the active variant is whole-union reassignment: the new tag and payload are stored together. Per-member payload stores and taking a payload member's address are rejects (S2). 

var x: U = .{ .i = 1 };
x = .{ .i = 5 };          // reassign tag and payload
x = .{ .box = .{ .w = 9 } };
var p: *U = &x;
p.* = U{ .i = 21 };       // through a pointer

The reused standalone repro/tagged_payload_store_reject.z98 pins both rejects (two level-0 error[3000], one per offending statement):

Shape Code Message (measured)
x.i = 5, b.box = .{ ... } error[3000] cannot store to a tagged-union payload member; assign the whole union instead (e.g. x = .{ .i = 5 })
&x.i, b.box.w = 7 error[3000] cannot take the address of a tagged-union payload member; assign the whole union instead (e.g. x = .{ .i = 5 })

The example in both messages is fixed wording; it does not rename the variable or the field. Before the payload-store fix these shapes were internal error[3043] ICEs. A whole-union switch with payload captures works normally (both the qualified Shape.circle and shorthand .box prong spellings bind the payload identically), and the mandatory else applies here as everywhere: a switch without it rejects level-0 error[3068] switch must have an 'else' prong. The reused fixture repro/mi_matrix/tagged_union_cmp_xmod pins a cross-module whole-union == against a variant (prints 1).

The .tag field of a tagged union

A tagged union has a synthetic .tag field typed u32. It holds the live variant's ordinal (declaration order), independent of any payload. A direct .tag access is paren-transparent and a pointer or many-pointer base auto-dereferences (p.tag, (*p).tag), so the read is of the pointee's ordinal and p.tag = v stores through it.

A member-shaped use of .tag gets contextual member sugar: an enum literal compared against the tag resolves against the base union's members and compares ordinals, yielding bool. All six comparison ops are hooked, the member may be on either side, and the qualifier may be shorthand, container-qualified, or a same-type alias.

Use (measured on the fixed compiler) Result
s.tag The ordinal as u32 (variant 0 prints 0).
s.tag == .circle, s.tag != Shape.circle, s.tag < Shape.empty, <=, >, >= bool; the member resolves to its ordinal and both sides are compared as ordinals.
Shape.circle == s.tag (member on the left) bool; accepted.
s.tag == ShapeAlias.circle (const ShapeAlias = Shape;) bool; a same-type alias qualifier is accepted.
switch (s.tag) { .circle => ..., Shape.empty => ..., else => ... } Member prongs resolve to ordinal case labels; the mandatory else applies.
switch (s.tag) { 0 => ..., else => ... } Numeric prongs are unchanged.
switch (s.tag) { .box => |v| ... } The capture binds a u32 copy of the ordinal (there is no payload).
s.tag == 0, @enumToInt(s.tag), const t = s.tag; Plain numeric uses; t is a u32 copy. switch (s) on the whole union is unchanged.
const t = s.tag; t == .circle Level-0 error[3076] unable to infer type of enum literal in comparison with a numeric operand (the sugar is per use, not per value).

The reject on the copied tag is exactly the class the reused standalone repro/copied_tag_compare_reject.z98 pins (four error[3076], one per comparison site, span on the literal). A typed-enum compare (c == .Red) stays accepted.

A member named tag

A union member named tag is permanently shadowed by the synthetic tag. Every .tag access on the union — value or pointer base — reads or writes the ordinal, never the same-named member's payload. The collision is accepted silently, but avoid the name. The member still exists as a variant: it may be used in a switch prong capture, in whole-union equality (u == U.tag), and in an initializer (u = .{ .tag = 99 }). A probe on union(enum) { tag: i32, other: i32 } printed the ordinal 0 for u.tag after .{ .tag = 99 }, while switch (u) { .tag => |v| ... } captured 99 and u == U.tag was true.

Printing a union

A bare {} chooses the form's printer. A bare union always compiles and prints the depth placeholder .{ ... }, never its fields. A tagged union prints its active variant (.{ .circle = 3 }) only when every variant carries a non-void, printable payload; the naked tag, an explicit void variant, or an unprintable payload makes the argument reject even when that variant is not active. A packed union of bool/integer members prints its fields; a packed-struct member is an unprintable payload.

Value, printed with {} Result (measured)
union { f: f32, u: u32 } .{ ... } (placeholder, always).
union(enum) { circle: i32, box: struct { w: i32, h: i32 } } .{ .circle = 3 }, .{ .box = .{ .w = 1, .h = 2 } }.
union(enum) { circle: i32, empty } (naked tag) error[3063] print argument type is not supported (no std.fmt printer).
union(enum) { circle: i32, empty: void } error[3063] (same message).
packed union { whole: u8, lo: u4 } .{ .whole = 5, .lo = 5 } (all fields, in declaration order).
packed union { whole: u8, halves: Halves } error[3063] (packed-struct member is unprintable).

The full aggregate-print closure rule and the other error[3063] shapes (array, slice, optional, error-union, void, nested packed aggregate fields) are on the builtins page. To avoid the reject, print the fields you mean (flags.whole, s.tag, a captured payload). An explicit specifier such as {d} on a union is a separate reject, error[3013] invalid print format specifier for the argument type.
