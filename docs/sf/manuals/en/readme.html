Read Me

The Z98 manual is a local, offline website. It is hand-authored static HTML with no external resources, so it works from a CD, a diskette set, or a directory on disk with no server and no network.

Reading paths

Six volumes. One reader enters at the volume that matches their background and reads forward. Nobody reads all six cover to cover.

Volume Title Entry state Exit state
IGetting StartedNever programmedWrites small working programs
IILearning Z98Programs in some languageFluent in Z98 syntax and idioms
IIIWorking in the EraFluent in Z98Ships software for 1998 hardware
IVReferenceAnyLooks things up
VHOWTOAnySolves a specific task
VIInternalsMaintainerCan modify the compiler
  • Never programmed → I → II → III → IV/V as needed
  • Knows C, C++, Java, or Python → skim I → II → III → IV/V as needed
  • Knows modern Zig → II (for the differences) → III → IV/V
  • Wants to use it now → V → IV
  • Maintainer → VI → IV → the engineering docs

Colophon

HTML 4.0 Transitional, authored in the conservative HTML 3.2/4.0 intersection, encoded ISO-8859-1. Baseline appearance is carried by presentational attributes and tables; the stylesheets are optional decoration. GIF assets only: no PNG, no SVG, no web fonts. One small JavaScript file, and every feature degrades to working HTML.

This is the English edition. The language bar lists Spanish and Simplified Chinese as not yet available; when they ship, each is a complete manual of its own, not a translation layered on this one.
