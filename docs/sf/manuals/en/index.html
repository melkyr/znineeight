Z98 Manual

English edition

Z98 is a small language that compiles to C89 and targets Pentium-class machines. This manual is its on-ramp: from never having written a program, to writing Z98 fluently, to shipping software for 1998 hardware, with a reference and a HOWTO set for lookup.

The manual is split into six volumes. Start with the table of contents to see the whole set, or read the read me page for the reading paths and the colophon.
