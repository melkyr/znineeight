Diagnostics

This page lists every member of the compiler's ErrorCode enum (sf/src/diagnostics.zig), alphabetically by name, with the number the compiler prints and the message it prints by default.

The printed number is the enum value, not the number in the name. The ERR_#### suffix is only a label; several names share a suffix and the suffix does not match the ordinal. For example, ERR_2012_ANYTYPE_NOT_SUPPORTED prints error[16], and ERR_1001_UNTERMINATED_BLOCK_COMMENT prints error[1]. Always read the ordinal from the Printed column.

The level is the first word: error (level 0), warning (level 1), or info (level 2). The human-readable printer emits [file:]line:col: error[N]: <message> (or error[N]: <message> when a code is raised without a source location); the ERR_*, WARN_*, and INFO_* spellings are enum member names only and are not printed. The Emission site column names the file:line that raises the code; a message assembled at run time from fragments is shown in its assembled form and the site is where it is assembled. A code with several distinct message shapes lists them separated by /, with run-time text marked <...>. Rows marked reserved are enum members with no emission site at seed v90; they are listed because they are members, but they are not raised.
