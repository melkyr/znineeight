Volume I — Getting Started

Enter here if you have never written a program. Leave able to write small working programs.

This volume is the on-ramp. It is short on purpose: it exists to get you to the point where Volume II makes sense. Chapters that introduce code end with a runnable program, a list of common mistakes, and a "Check yourself" exercise; the chapters that have no code end with "Check yourself".

How to read this

This manual is a book that happens to be a website. It ships as static HTML on a disk, with no network and no server, so every page is a file you can open, print, and keep. The prose is the manual; the HTML is only the binding.

What a manual is

A manual is not a tutorial you finish and forget. It is something you keep beside the machine, written so that a reader who has never done this before can start at the first page and arrive at the last with a working skill. This one teaches a language called Z98 and the discipline of writing for 1998 hardware. It is honest about both: where Z98 is the wrong tool, it says so and points you at the era's other tools.

The sidebar

The narrow column on the left is the sidebar. Its top links are the same on every page: Title page, Contents, Read me, and Search. Below them is the table of contents for the volume you are reading, so you can jump to any chapter without going back to the master contents. The chapter you are on is shown in bold; a chapter whose page does not exist yet is plain text marked (planned) and is not a link.

The language bar

The bar at the top of the sidebar lists the languages the manual ships in. English is the current edition. Spanish and Simplified Chinese are shown as plain text marked (not yet available); each will be a complete manual of its own, not a translation layered on this one. When they ship, they become links to the equivalent page.

Printing the manual

Every page links two stylesheets: z98.css for the screen and z98-print.css for print. The print sheet hides the sidebar and the language bar, sets the body to 11-point type, and draws a hairline border around code blocks so they survive photocopying. Choose Print (or press Ctrl-P) and the page comes out as a book page rather than a web page. Page breaks are not forced; forcing them is a later CSS feature, and this manual uses CSS1 only.

The reading paths

Six volumes, each with a stated entry state and exit state. One reader enters at the volume that matches their background and reads forward; nobody reads all six cover to cover. The paths printed on the back cover of every volume are:

  • Never programmed → I → II → III → IV/V as needed
  • Knows C, C++, Java, or Python → skim I → II → III → IV/V as needed
  • Knows modern Zig → II (for the differences) → III → IV/V
  • Wants to use it now → V → IV
  • Maintainer → VI → IV → the engineering docs

If you have never written a program, you are in the right place: this volume is the first leg of the first path.

The callouts

The manual sets off five kinds of aside, each with its own icon and colour, so you can tell at a glance whether a paragraph is an aside, a shortcut, a warning, a trap, or the manual being straight with you.

Note. The chapter list marks an unwritten chapter (planned). It is plain text, not a link, until its page ships.
Tip. The Contents link at the top of the sidebar and in the footer always returns you to the master table of contents for all six volumes.
Warn. Read the chapters in order. A later chapter assumes the types and functions an earlier one defined; skipping ahead leaves names the compiler cannot resolve.
Caution. Never edit the generated C by hand. Change the .z98 source and rebuild; the next build overwrites the generated files.
Honest note. This manual teaches Z98, a small language for 1998 machines. Modern languages do more with less effort, and the era's real choices were C89 and C++98. Where another tool is the better choice, this manual says so.

The last one matters most. The manual earns its keep by telling you when Z98 is the wrong tool; when you see the warm grey box, read it before you decide what to build.
