Your First Program

This is the smallest complete Z98 program: it prints one line and stops. Type it in, build it, and run it. Everything later in the manual is built from pieces like this one.

The program

const std = @import("std");

pub fn main() !void {
    std.io.print("Hello from Z98!\n");
}

What the lines mean

const std = @import("std"); pulls in the standard library and gives it the name std. The compiler resolves @import("std") to the shipped standard library, so you do not copy library files into your own project.

pub fn main() !void { ... } declares the program's entry point. fn starts a function, main is its name, and the empty parentheses mean it takes no arguments. pub makes it visible outside its own module; the compiler looks for pub fn main and wraps it in the C int main that the operating system calls. The !void after the parentheses is the return type: a void error union, meaning the function returns nothing or an error. A function that returns !void and reaches its closing brace without a return is treated as success, so main needs no explicit return.

std.io.print("Hello from Z98!\n"); writes the string to standard output. The \n at the end is a newline character, so the shell prompt starts on the next line. print is special in Z98: it takes a string and, when there are values to show, a tuple of arguments (for example std.io.print("count: {}\n", .{n});). This first program has nothing to substitute, so the string is all it needs.

Building it

Build the compiler once from the committed seed (from the repository root), then emit and compile the program: 

bash scripts/seed/build_from_seed.sh release/seed/zig1-seed.tgz /tmp/manual_seed

That produces /tmp/manual_seed/zig1_5_clean, the compiler, with the standard library beside it in /tmp/manual_seed/lib/. Now translate the program to C89 and build it: 

$ mkdir -p /tmp/manual_out
$ /tmp/manual_seed/zig1_5_clean -o /tmp/manual_out docs/sf/manuals/src/vol1/hello.z98
$ cd /tmp/manual_out && sh build_target.sh linux hello
Building for linux...
Built: hello
$ ./hello
Hello from Z98!

The mkdir creates the output directory, which the compiler requires to exist. The next command translates hello.z98 into C89 and writes it, with the runtime and a build_target.sh, into /tmp/manual_out. The one after that compiles the C with gcc -m32 and links the executable hello. The generated C draws a long list of warnings from gcc; the emitted script does not use -Werror, so they do not stop the build. The last command runs the program, which prints its one line.

Running under Windows 98

The same program builds for Win9x. src/build_owc.bat compiles the emitted C89 with OpenWatcom's wcc386 and links a console hello.exe; run from a Windows 98 command prompt, it prints the same line. The screenshot below will be captured on real hardware.
