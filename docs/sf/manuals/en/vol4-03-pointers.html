Pointers

A pointer is a value holding the address of another value. Z98 spells pointer types in the Zig style — a * followed by the pointee type — and it splits the two qualifiers: const is enforced by the frontend and dropped from the emitted C, while volatile is enforced by the frontend and preserved in the emitted C. This page is the lookup for the pointer shapes, the address and dereference operators, the indexing and slicing rules, pointer arithmetic, and the pointer builtins.

The authority is the parser (sf/src/parser.zig: parserParsePtrQualifiers at 1148-1162, parserParsePtrType at 1164-1173, and parserParseBracketType at 1175-1204), the single-item-pointer checks in sf/src/semantic_analyzer.zig (semanticAnalyzerReportIllegalPtrIndex at 1052-1073 and semanticAnalyzerCheckSinglePtrSlice at 1108-1180), both diagnostic codes error[3066]/error[3067], and the qualifier rules (semanticAnalyzerVolatileDrop at 2584-2590 and semanticAnalyzerConstDiscard at 2601-2670). Every rule and reject below was reproduced on seed v90 with a seed probe; the reused fixtures are named where one exists.

Pointer shapes

Each shape is a distinct type. All pointers are 4 bytes with alignment 4 in the 32-bit model (see Types). The “C89 emission” column is the measured spelling of a parameter of that type in the generated C.

Spelling Kind C89 emission Notes
*T single-item pointer T* One item; read and write through p.*.
*const T single-item, read-only T* (const dropped) Writing through it is a frontend reject; the qualifier is not emitted.
*volatile T single-item, volatile volatile T* Reads and writes may not be elided; the qualifier is emitted.
*const volatile T single-item, both qualifiers volatile T* (const dropped) Both flags are accepted; the parser records them independently.
[*]T many-item pointer T* Points at a run of items; carries no length; C-style p[i].
[*]const T many-item, read-only T* (const dropped) Writing through an element is a frontend reject.
[*]volatile T many-item, volatile volatile T* For memory-mapped runs of registers.
**T, ***T, … multi-level pointer T**, T***, … Every level is dereferenced explicitly, one .* per hop.
*[N]T pointer to a fixed-size array Arr_T_N* Auto-deref indexing: pa[i] indexes the pointee array.
fn(P) T, ?fn(P) T function pointer (optional-wrapped) function-pointer typedef A function value coerces only to an exact signature match; see below.

[]T and []const T are the length-carrying slices, not pointer types; they are the arrays and slices topic (planned). A slice coerces to a many-item pointer through its .ptr.

const stops at the frontend; volatile reaches C

The two qualifiers promise to different audiences. A *const T stops a write in Z98 source and then emits as a plain T*, so a C function that receives it can still write through it. A *volatile T is emitted as volatile T*, so the C compiler honors it as well. Measured emissions: *const u32 → unsigned int*; *volatile u32 → volatile unsigned int*; [*]const u32 → unsigned int*; [*]volatile u32 → volatile unsigned int*; *const volatile u32 → volatile unsigned int*.

An implicit pointer coercion may add a qualifier but must never discard one. Both discard directions are level-0 error[3000]; the volatile rule also blocks @ptrCast.

Coercion Result Diagnostic
*T → *const T / *volatile T accepted —
*const T → *T rejected error[3000] cannot implicitly discard 'const' qualifier
*volatile T → *T rejected error[3000] cannot implicitly discard 'volatile' qualifier; use @volatileCast to remove it
[*]const T → [*]T rejected error[3000] cannot implicitly discard 'const' qualifier
[]const T → []T / [*]T rejected error[3000] cannot implicitly discard 'const' qualifier

The only sanctioned removal of volatile is @volatileCast(T, expr), which requires a volatile source and a destination with the same base type. const has no removal builtin; a const-discarding cast is written with @ptrCast and is a deliberate reinterpretation, not an implicit coercion.

Address-of and dereference

  • &x produces a pointer to x. The operand must be an lvalue: a variable, a field, or an array element. Taking the address of a literal or a temporary is rejected with error[3043] internal: unsupported address-of l-value (measured for &5 and &f()).
  • p.* is the value the pointer points at; p.* = v writes through it. Dereference is the postfix .*, not C's prefix *. Multi-level pointers dereference one hop at a time: pp.*.* reaches the i32 behind a **i32.
  • ptr.field auto-dereferences a single-level pointer to a struct (emitted as ptr->field). It applies through exactly one pointer level; a **Point needs pp.*.field.

Indexing: p[i]

p[i] is defined only for a many-item pointer ([*]T, no length) and for a pointer to a fixed-size array (*[N]T, Zig's auto-deref indexing). Indexing any other single-item pointer — *T, *const T, *volatile T, or a multi-level pointer — is a compile-time reject, even for index 0. A many-pointer index is as unchecked as C's p[i]; the length-checked form is a slice.

Base base[i] Diagnostic (measured)
[*]T, [*]const T, [*]volatile T accepted —
*[N]T accepted (auto-deref) —
struct/union array field s.arr[i] accepted (element decay) —
*T / *const T / *volatile T rejected error[3066] type '*T' does not support indexing + note operand must be an array, slice, tuple, or vector
**T (multi-level) rejected error[3066] type '**T' does not support indexing + the same note
type base (*p)[i] rejected error[3066] unable to resolve comptime value + note types must be comptime-known

The message spells the base type backward, including its qualifiers and levels (*i32, *const i32, *volatile i32, **i32). Measured: var p: *i32; p[0] reports type '*i32' does not support indexing; pp[0] on **i32 reports type '**i32' does not support indexing; (*p)[0] reports the unable to resolve comptime value wording.

Slicing a single-item pointer

A *T (or *const T/*volatile T) may be sliced only with the three comptime-known bounds below; the result carries the base's qualifiers. Every other form rejects error[3067]. The reused fixture repro/mi_matrix/stdlib_ptrslice_ok_xmod pins the three legal forms and their qualifier carry.

Form on p: *T Result type Diagnostic (measured)
p[0..0] *[0]T —
p[0..1] *[1]T —
p[1..1] *[0]T —
p[0..] (open) rejected error[3067] slice of single-item pointer must be bounded
p[0..n] (runtime) rejected error[3067] unable to resolve comptime value + note slice of single-item pointer must have comptime-known bounds
p[0..2], p[1..0], p[-1..1] rejected error[3067] slice of single-item pointer must have bounds [0..0], [0..1], or [1..1]

*[N]T slicing (and pa.*[i]) follows the ordinary array/slice path documented on the arrays and slices page (planned). For a *T result of length zero, .len is 0 and an index rejects error[3062]; the emitted C array typedef is clamped to [1] (C89 has no zero-length array), which is a C-model clamp only.

Pointer arithmetic

The arithmetic operators are accepted for pointer operands. An integer offset scales by the pointee size (ordinary C pointer arithmetic); subtracting two pointers yields the signed difference of the two addresses.

Expression Result Emission / measured value
ptr + i, ptr - i same pointer type as ptr C pointer arithmetic, scaled by the pointee size. Measured: mp + 2 on [*]i32 reads element 2; on a single-item *i32, p + 1 emits p + 1.
i + ptr same pointer type as ptr Commutative form, accepted.
ptr1 - ptr2 isize A signed subtraction of the two addresses. Measured: q - mp for q = mp + 2 over [*]i32 yields 8 (the byte offset), not 2 (the element count).

The offset operand is an unsigned integer or an untyped integer literal; ptr + i is typed the pointer, and ptr1 - ptr2 is typed isize (semanticAnalyzerResolveArithmetic, semantic_analyzer.zig:2277-2284). Because indexing a single-item pointer is still rejected (above), the idiomatic way to step an item pointer is p + n followed by (p + n).*, or an explicit [*]T.

Function pointers

A function pointer is a fn(P1, P2) T type, optionally wrapped once as ?fn(...) T. A function value may be assigned or coerced only to a target whose signature matches exactly: return type, parameter count and types, variadic flag, and calling convention. A mismatch is a level-0 error[3000] at the coercion site, including through one level of ?fn wrapping; an explicit @ptrCast to a mismatched signature stays legal. The reused fixtures repro/mi_matrix/fn_ptr_signature_ok_xmod and repro/mi_matrix/fn_ptr_signature_reject_xmod pin the accept/reject sets. See the coercion table on Types.

Pointer builtins

Casts and pointer/introspection are provided by builtins, recognized by name; there is no pointer library. The full entries are on the Builtins page. The pointer set and its measured rejects:

Builtin Result Reject (measured)
@ptrCast(T, expr) Reinterpret a pointer as pointer type T, without looking at the pointee. error[3049] @ptrCast requires exactly two arguments: @ptrCast(T, expr); error[3000] @ptrCast cannot discard the 'volatile' qualifier; use @volatileCast to remove it.
@ptrToInt(expr) / @intFromPtr(expr) Pointer to usize; the two names are the same operation. —
@intToPtr(T, expr) Integer to pointer, result type named explicitly. —
@ptrFromInt(expr) Integer to pointer, result type taken from context. error[19] cannot infer pointer type for @ptrFromInt; annotate the target variable type.
@bitCast(T, expr) Same-size integer-to-integer bit reinterpretation. error[19] @bitCast requires same-size integer source and destination types.
@volatileCast(T, expr) Remove volatile; source must be a volatile pointer and T the same base type. error[3000] @volatileCast requires a volatile pointer source and a destination with the same base type.
@fieldParentPtr(T, "field", expr) *T to the containing struct from a pointer to one of its fields. —

@intFromPtr/@ptrFromInt are the modern aliases of @ptrToInt/@intToPtr. The reused fixture repro/mi_matrix/builtin_ptr_roundtrip_xmod round-trips a @intFromPtr address through @ptrFromInt and stores 42; repro/mi_matrix/builtin_fieldparentptr_xmod recovers &outer from &outer.inner and prints 1. The Volume II sample docs/sf/manuals/src/vol2/pointers.z98 (rebuilt and run on seed v90) exercises all six casts and prints the round trips.
