Volume II — Learning Z98

Enter here if you already program in some language. Leave able to write Z98 fluently, in its own syntax and idioms.

Volume I teaches programming. This volume teaches the language. It assumes you do not need the machine explained, and it spends its pages on the parts of Z98 that differ from the languages you already know.

This volume assumes you program. If you do not, read Volume I — Getting Started first: it exists to get you to the point where this volume makes sense. Every chapter here takes "variable", "function", and "loop" as words you already use.

How to read this

The manual is six volumes. Each one states an entry state and an exit state, and a reader enters at the volume that matches their background and reads forward; nobody reads all six cover to cover. The paths printed on the back cover of every volume are:

  • Never programmed → I → II → III → IV/V as needed
  • Knows C, C++, Java, or Python → skim I → II → III → IV/V as needed
  • Knows modern Zig → II (for the differences) → III → IV/V
  • Wants to use it now → V → IV
  • Maintainer → VI → IV → the engineering docs

This volume is the whole of the third path and the second stop on the first two.

How a chapter is built

A chapter is 8–14 pages. A chapter with a program opens with the argument, then works that program in full: the page shows the program, which is a real file under docs/sf/manuals/src/vol2/, and the transcript that file produced when it was compiled and run. The chapter closes with Common mistakes — the thing you will reach for from the language you already know, and the Z98 way instead — and Where to go next, which points at the next chapter and the Reference pages for the same subject. A chapter that carries no program still ends with Where to go next.

When a passage is a limit, a friction point, or an honest word about the era's other tools, it is set off as an Honest note in a grey box. The five callouts — note, tip, warn, caution, honest — are the ones Volume I introduces and displays on its title page.

The examples and the compiler

The examples live in docs/sf/manuals/src/vol2/, beside the pages that use them. They are compiled with the compiler rebuilt from the committed seed; the rebuild recipe is in Volume I, Installing the Toolchain, under "Path one". This volume reuses the toolchain that chapter installs and does not repeat its commands.
