The standard library

@import("std") resolves to sf/src/std.zig, which does nothing but re-export thirteen modules. This page is the lookup for that surface: one section per re-exported module, every public declaration quoted verbatim from the sf/src/std_*.zig file that defines it, with its return type and error set. The language-level calls these modules are built from are on Builtins; the tutorial treatment is Volume II, The standard library tour.

The surface is concrete only. Z98 has no generics, no anytype, and no @Type, so no module is parameterized: where a generic language would write one copy or one popcount, these modules ship a named variant per element width or signedness (copyU8/copyU32, popcount32/popcount64, printI32/printU32, and so on). Every function is a plain Z98 function that can be read in the source.

Two modules name an imported type through a file-local alias. Quoted verbatim, those signatures read *arena_mod.Arena (an alias for std.arena.Arena, used by std.str, std.os, and std.buf) and *buf_mod.Buf (an alias for std.buf.Buf, used by std.debug.backtrace). The signature is otherwise exactly as the source writes it.

std.io

std.io is where bytes leave and enter the program. Output splits into two families: the builtin-backed functions (write, writeByte, printInt) and print, the compiler's format-string entry point that routes through std.fmt. File I/O is a PAL surface, not C stdio.h: a handle is a usize that arrives as an optional because open can fail.

Function Signature Returns / error Purpose

writeStr pub fn writeStr(s: [*]const c_char) void void Write a NUL-terminated C string; length is found by scanning.
print pub fn print(s: [*]const c_char, ...) void void Format-string entry point; the compiler lowers it into std.fmt calls. The only variadic form Z98 supports.
printInt pub fn printInt(n: i32) void void Write a signed 32-bit integer in decimal.

std.fmt

std.fmt is the engine under std.io.print. It is auto-imported whenever a print is lowered, so a user never imports it by hand; its functions are public so the generated cross-module calls can name them. std.arena

The arena is a bump allocator. You supply the storage; it never allocates. There is no free and no deinit — reclaiming memory means resetting the bump pointer. See Volume II, The arena.

std.str

std.str operates on byte slices, never NUL-terminated strings. The zero-copy functions return views into the input: split and splitLines allocate only the outer array of slices, and the trim family returns a narrower slice over the same bytes. Only join, replace, and repeat allocate a new string, and they read their input without mutating it, so from and to may alias s. The allocating functions name their error with !; it is inferred as the arena's error{OutOfMemory}.

std.debug

std.debug is the logging and assertion module. log and logInt write to standard output; assert and panic write a message and then trap, so they never return. The module also owns the trap surface: setTrapHandler installs a handler that receives the register context, and backtrace walks the frame chain into a std.buf buffer.

std.net

std.net is a set of target-selected bindings, not a protocol framework. On Windows it reaches Winsock 1.1 (wsock32, WSAStartup(1,1)); on the POSIX target it reaches libc. The public API hides the per-OS symbols behind names such as accept and close. Socket is a signed i32 where -1 signals failure. NetError deliberately excludes OutOfMemory (no path allocates); an unrecognised OS code collapses to Io, and a receive-path WouldBlock is normalised to Timeout.

std.async

The coroutine builtins live in the language; the bookkeeping lives here. std.async is a concrete cooperative scheduler with a per-task LIFO child-frame pool; there are no generics and no module-scope mutable globals, so the caller supplies all storage. The root frame lives in the buffer passed to @asyncInit and is outside the pool; the Context sits at the head of a caller-supplied buffer that must be 8-aligned. The compiler side of this contract is on the async page (planned); the four @async* builtins are on Builtins.

std.bits

std.bits is pure computation on u32 and u64. Z98 has no bit builtins beyond @bitCast, so every operation is a hand-written loop. All functions are total except extract and insert, which trap on out-of-range offsets via unreachable (off < 32, len ≤ 32, and off + len ≤ 32).

std.os

std.os exposes process-level information. The argument surface is explicit: the compiler's main wrapper forwards argc and argv only when the Z98 main declares them, and the user calls initArgs once. After that, argc and argv are ordinary reads. cwd takes an arena because the directory is copied into memory you own.

std.time

std.time provides a monotonic counter, a wall clock, and sleep. ticksMs is milliseconds since boot on Windows and wall-clock milliseconds since the epoch on POSIX, truncated to 32 bits; it wraps every 49.7 days. highRes is the monotonic source, with its unit given by highResFreq.

std.buf

std.buf is a growable byte buffer. It is bytes only, not a general container, and it owns no storage: the arena behind it does. Growth doubles the capacity, and clear keeps the storage while resetting the length. There is no deinit; resetting the arena reclaims everything. The endian-tagged append functions exist because wire and file formats need them.

Modules shipped but not re-exported

The library directory beside the compiler holds more std_*.zig files than the thirteen re-exports. A name that is not in the table above does not resolve as std.<name>; the compiler rejects it (the measured diagnostic is error[3074], shown on Volume II, The standard library tour). Reachable modules that exist in sf/src but are not part of the std namespace: std_base64, std_crypto, std_file, std_heap, std_hex, std_map, std_parse, std_rle, std_sort, std_stdin, std_stream, and std_utf8. Four further files (std_file_pal, std_os_pal, std_stdin_pal, and std_time_pal) are the per-OS support layer used by re-exported modules; they are not public modules at all.
