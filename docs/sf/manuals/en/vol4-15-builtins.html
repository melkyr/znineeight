Builtins

Builtins are the compiler's own functions. They are written @name(...) and recognized by name; an unknown or unsupported builtin is rejected with error[3000]: unsupported builtin function. This page is the lookup: every builtin the compiler supports, grouped as the language reference groups them, one short entry each. It is not a tutorial.

Everything below is the surface documented in Language_Spec_Z98.md §4 and implemented by the compiler. There is no @typeInfo, no @typeName, and no other builtin beyond those listed here.

Cast and conversion

Each names an explicit conversion. Except where noted, the first argument is the result type.

@ptrCast(T, expr)

Explicit pointer cast. Both the target type and the expression must be pointer types. 

var p: *u8 = @ptrCast(*u8, q);

@ptrToInt(expr) / @intFromPtr(expr)

Pointer to integer. The result is a usize; @intFromPtr is the modern alias. 

var addr: usize = @ptrToInt(p);

@intToPtr(T, expr)

Integer to pointer, with the result type named explicitly. 

var p: *u8 = @intToPtr(*u8, addr);

@ptrFromInt(expr)

Integer to pointer, with the result type taken from context. 

var p: *u8 = @ptrFromInt(addr);

@fieldParentPtr(T, "field", expr)

Pointer to the containing struct, from a pointer to one of its fields. 

const owner: *Point = @fieldParentPtr(Point, "x", xptr);

@bitCast(T, expr)

Same-size integer-to-integer bit reinterpretation. Source and destination must be integers of the same size. 

var u: u32 = @bitCast(u32, i);

@volatileCast(T, expr)

Removes the volatile qualifier. The source must be a volatile pointer and the target the same base type. 

var p: *u8 = @volatileCast(*u8, vp);

@intCast(T, expr)

Checked integer conversion or width change. Under the default -fsafe the conversion is range-checked and traps on overflow. 

var n: u8 = @intCast(u8, x);

@floatCast(T, expr)

Float conversion. It is not runtime-checked, so narrowing may lose precision. 

var d: f64 = @floatCast(f64, f);
var f2: f32 = @floatCast(f32, d);

@intToFloat(T, expr)

Integer to floating point. T is a float type and expr is an integer type. 

var d: f64 = @intToFloat(f64, n);

@intToEnum(T, expr)

Integer to enum value of type T. 

var c: Color = @intToEnum(Color, n);

@enumToInt(expr)

Enum value to its underlying integer type. 

var n: u8 = @enumToInt(c);

@as(T, expr)

Explicit type coercion. 

var x: i64 = @as(i64, n);

Introspection

These are evaluated at compile time and yield a usize constant (the bit variants a bit count). T must be a complete type.

@sizeOf(T)

Size of type T in bytes. 

const n: usize = @sizeOf(Point);

@alignOf(T)

Alignment requirement of type T in bytes. 

const a: usize = @alignOf(Point);

@offsetOf(T, "field")

Byte offset of a field within a struct or union. The field name is a string literal; for a union the offset is 0. 

const off: usize = @offsetOf(Point, "y");

@bitSizeOf(T)

Size of type T in bits. 

const bits: usize = @bitSizeOf(Point);

@bitOffsetOf(T, "field")

Bit offset of a field within a struct or union. 

const bit: usize = @bitOffsetOf(Point, "y");

Runtime

Ordinary runtime operations, emitted directly as C89.

@putChar(c)

Writes a single character. 

@putChar('A');

@stdoutWrite(ptr, len) / @stderrWrite(ptr, len)

Writes len bytes from ptr to stdout or stderr. 

@stdoutWrite(msg.ptr, msg.len);

@getChar()

Reads a single character as a u8. 

var c: u8 = @getChar();

@exit(code)

Terminates the process with code. 

@exit(1);

@sleepMs(ms)

Sleeps for ms milliseconds. 

@sleepMs(100);

@isWindows()

Compile-time-folded target predicate; true only for the Windows target. 

if (@isWindows()) {
    @consoleClear();
}

@consoleClear()

Clears the console. 

@consoleClear();

@consoleGotoxy(x, y)

Moves the console cursor to column x, row y. 

@consoleGotoxy(0, 0);

@consoleSetColor(fg, bg)

Sets the console foreground and background colour. 

@consoleSetColor(7, 0);

@panic(msg)

Evaluates msg, writes panic: <msg>\n to stderr, then traps. It is typed noreturn and is not a no-op. 

@panic("bad state");

C varargs

These access a C va_list inside a variadic function.

@cVaStart

Initializes a C va_list. It is only valid in a variadic function. 

var vl: va_list = undefined;
@cVaStart(&vl);

@cVaArg(ap, T)

Fetches the next argument from the list as type T. 

var n: i32 = @cVaArg(&vl, i32);

@cVaEnd

Finishes the traversal of the list. 

@cVaEnd(&vl);

Async / coroutines

Z98 has cooperative, stackless coroutines, but there is no async/await keyword and no Future(T). Coroutine state is type-erased to *void, and the scheduler lives in the std.async library. A function is suspending when it contains @asyncSuspend or calls a suspending function; every suspending function is compiled to a step machine.

@asyncFrameSize(fn)

Compile-time byte size of a suspending function's root frame. fn must resolve to a known suspending function. 

const sz: usize = @asyncFrameSize(worker);

@asyncInit(ctx, buf, fn, args)

Initializes a coroutine root frame in buf for the suspending function fn and returns it as *void. args is the parameter record, passed as a plain *const void. 

var frame: *void = @asyncInit(ctx, buf, worker, @ptrCast(*const void, &args));

@asyncSuspend(data)

An explicit suspension point; valid only inside a suspending function. The data operand is type-checked but not propagated. 

_ = @asyncSuspend(null);

@asyncResume(frame, arg)

Resumes the coroutine rooted at frame. Returns null when the coroutine has finished, and non-null while it is still suspended. 

var r: ?*void = @asyncResume(frame, arg);

Declarations

@import(path)

Includes another module. The path is resolved relative to the current module. The standard library is imported as @import("std"), which re-exports io, arena, str, mem, math, debug, and net; symbols are reached with dot notation. 

const std = @import("std");
std.io.print("hi\n", .{});

@cInclude("header.h")

Emits a C header #include. It is used by the extern OS bindings. 

@cInclude("zig_runtime.h");

Formatted print

A call whose callee is named print (for example std.io.print) is a compiler special case: the compiler decomposes the format string and emits one runtime print call per argument. The arguments must be a tuple literal (.{...}) or a tuple variable. The specifiers are {} (default, decimal), {d} (decimal), {x} (hex), {c} (character), and {s} (string); any other specifier is rejected with error[3013]. This is the only variadic form Z98 supports; there is no anytype. The shipped wrapper is std.io.print(s: [*]const c_char, ...) void. 

std.io.print("fact(10) = {}\n", .{fact(10, 1)});
std.io.print("{c}", .{ch});
