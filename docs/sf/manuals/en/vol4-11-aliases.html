Type aliases

A type alias binds a name to a type: const T = <type>;. Once declared, T is a type name and may be used anywhere the underlying type may. This page is the lookup for the declaration sites, the alias targets, the positions an alias may appear, the pub cross-module rules, and the measured limits.

Authority: the spelling is docs/reference/Language_Spec_Z98.md §1.7; registration is the var_decl branch of symbol_registrator.zig:248, with the alias write-back in front_resolution.zig (the const_alias_prepass.zig prepass is retained but dormant — 0 CAP hits); resolution is type_resolver.resolveTypeExprFull (type_resolver.zig:1776); the local-alias guard is semantic_analyzer.zig:5840 and the value-position guard is semanticAnalyzerExprIsTypeValue (semantic_analyzer.zig:6465). Every rule below was reproduced on the fixed compiler (md5 821481e69df63fc0cf69176fdaaf9dd9); reused repro/mi_matrix/typealias_* fixtures are named where one exists.

Syntax and declaration site

The alias is a module-scope declaration whose value is a type. The documented spelling is const; adding pub makes the alias visible to importers. A function-local alias is rejected.

Form Scope Result (measured)
const T = <type>; module Registers T as a type alias: it is a type name in annotation, parameter, return, field, element, wrapper, and builtin positions.
pub const T = <type>; module As const, and visible to importers as mod.T or @import("m.zig").T.
const T = <type>; function body error[3000] local type aliases are not supported; bind the container declaration directly, plus a follow-on error[20] for every use of T.
const T: type = <type>; module Not an alias. T is a value whose type is type; using it as a type mismatches (target: type). 
const MyInt = i32;                          // primitive
const Buf   = []u8;                         // slice
const Point = struct { x: i32, y: i32 };    // anonymous aggregate
pub const Color = enum { Red, Green, Blue };
const Num   = MyInt;                        // alias of an alias

The registrar keys on the declaration's initializer being a type expression, but a module-scope var V = i32; binds a type value with var and is rejected (error[3000], source: type / target: type): a type value must be const/comptime. The Reference documents the const form.

Alias targets

Every type form is a legal alias target except the two marker names noreturn and anytype (parser error[2000]) and the type metatype itself (const T = type; is error[3000]; Z98 does not model the metatype). Sizes below are @sizeOf of the alias.

An alias used in a type position that names nothing resolvable is a level-0 error[20], emitted once per unresolved leaf. A wrapper is walked to its inner leaf: *Bogus, ?Bogus, and [3]Bogus each report Bogus once. A qualified mod.unknown reports the whole node.

Name erasure and measured limits

An alias is resolved to its underlying type at registration. Two measured behaviors follow.

Case Measured
Alias to a primitive or an existing named type Erased. const MyInt = i32; emits a field as int; MyInt appears nowhere in the .c. @offsetOf(MyInt, "x") reports error[3072] expected struct type, found 'i32', and a call mismatch note reads target: i32.
Alias naming an anonymous aggregate Adopted as the type's name. const Point = struct { ... }; emits struct zT_EAA8EF31_Point in the header and C, the same symbol in-module and cross-module.
Function-local alias error[3000] local type aliases are not supported; bind the container declaration directly. Compound local forms (*E, E!i32, [2]E, ?E) reject with one error[3000] each.
Annotated as type const T: type = i32; is not an alias; T is a value of type type and a type use mismatches.
Inferred-length array const A = [_]i32; rejects error[3000] unable to infer array size.
Alias in a value position var x = T; rejects with error[3000] at the initializer (source: type, target: type or the annotation's kind); rc 2, 0 .c. The same guard rejects a bare builtin (var y = i32;), the metatype (const T = type;), and a named type value on the RHS of an assignment, a call argument, or a return (source: type). The alias is a type, not a value. Function-local var x = i32; / var x = A; remain accepted (documented residual).
@sizeOf of each target Measured line for [3]i32 []i32 [*]u8 *u8 struct{i32,i32} enum union ?i32 error{Bad}!i32 fn(i32)i32 u33 is 12 8 4 4 8 4 4 8 8 4 8.
