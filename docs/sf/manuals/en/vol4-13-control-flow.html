Control flow

Control flow is the set of statement forms that choose, repeat, or dispatch: if/else, while, for, switch, the labels and the break/continue transfers that target them. This page is the lookup for each form, its captures, the mandatory switch else, and the diagnostics that bound them.

Authority: the spelling is docs/reference/Language_Spec_Z98.md §3.1–§3.2. The parser entries are parserParseIfStmt (parser.zig:1776), parserParseWhileStmt (:1854), parserParseForStmt (:1906), parserParseSwitchExpr (:979), parserParseLabeledStmt (:1573), parserParseBreakExpr (:2000), and parserParseContinueExpr (:2017). The semantic rules are semanticAnalyzerReportSwitchWithoutElse (semantic_analyzer.zig:4185), semanticAnalyzerCheckConditionType (:5481), semanticAnalyzerCaptureType (:635), semanticAnalyzerResolveForHeader (:5631), semanticAnalyzerResolveWhileHeader (:5705), and semanticAnalyzerReportSwitchCaseQualifier (:4200); the transfers lower at lower.zig:8342 (break) and :8367 (continue). Every rule below was reproduced on the fixed compiler (md5 821481e69df63fc0cf69176fdaaf9dd9); reused repro/mi_matrix/* fixtures and docs/sf/manuals/src/vol2/control.z98 are named where one exists.

if: statement and expression

The if statement runs one arm on a bool condition; braces are optional and a single-statement body is normalized into a synthetic block. The if expression yields a value and needs both arms.

Form Rule (measured)
if (cond) statement
if (cond) statement else statement		Statement form; braces optional; the body may itself be an if.
if (cond) a else bExpression form; braces not required; used as a value, an else is required.
if (cond) statement; else ...error[2000] ';' not allowed before 'else' - use braces: if (cond) { ... } else { ... }. Omit the semicolon, or brace both arms.
if (non-bool) (no capture)error[3058] condition must be of type 'bool'.
if (opt) |v| ...Capture form; binds the payload on the present branch. The else arm sees the absent case.
if (x) |v| ..., x not optionalerror[3058] capture condition must be an optional or error union type.
value = if (cond) a;error[3059] if expression without 'else' cannot be used as a value (its type is 'void'), unless the condition is comptime-known true.
fn classify(value: i32) i32 {
    if (value < 0) return -1;             // braces omitted
    if (value == 0) return 0;
    return 1;
}

var n: i32 = 7;
if (n > 5) n = 8 else n = 9;              // brace-less, no ';' before else
const kind: i32 = if (n == 8) 1 else 2;   // if expression

var maybe: ?i32 = 5;
if (maybe) |v| {                          // optional capture
    std.io.print("capture {}\n", .{v});
} else {
    std.io.print("capture none\n", .{});
}
const fallback: i32 = if (maybe) |v| v else -1;   // capture in expression

The value if merges the two arm types; a non-void arm with no else is the error[3059] above. A capture condition is an optional or an error union; a plain bool is written without bars. The error half of a capture, else |err|, does not parse at all (error[2000] expected expression) — error unions are the Error expressions page's subject (planned).

while: condition, continue-expression, capture

while (cond) : (iter) body tests cond, runs the body, then evaluates iter before testing cond again. Braces are optional and the continue-expression is optional.

Form Rule (measured)
while (cond) bodyPlain loop; the condition must be bool.
while (cond) : (iter) bodyiter runs after the body on each iteration, before the condition is re-tested; continue still reaches it.
while (true) { ... break; }The do/while replacement; do ... while is dropped. A continue here skips the exit test and re-enters the body.
while (opt) |v| bodyCapture form for an optional; loops while the value is present and ends when it is null.
while (non-bool), while (x) |v| non-optionalerror[3058], the same two messages as if.
var i: i32 = 0;
var sum: i32 = 0;
while (i < 6) : (i += 1) {       // iter runs after the body
    if (i == 2) continue;
    sum += i;
}                                 // i 6, sum 13

var count: i32 = 0;
while (true) {                    // do/while replacement
    if (count == 3) break;
    count += 1;
}

var down: ?i32 = 3;
var total: i32 = 0;
while (down) |v| {                // optional capture
    total += v;
    down = if (v > 1) v - 1 else null;
}

for: iterables, captures, and ranges

for (iterable) |item| body visits every element; a second capture provides the index. Braces are optional.

Iterable Item type (measured)
array [N]TT, by value.
slice []TT, by value.
pointer-to-array *[N]Tauto-derefs and visits the T elements; no explicit deref needed.
range start..endusize; end is exclusive. The inclusive start...end spelling does not parse.
Form Rule (measured)
for (x) |item| bodyOne capture; iterates every element.
for (x) |item, index| bodySecond capture is the usize index, counting from 0.
for (x) |_| body, |_, index|_ discards a capture; a discarded name is not bound and cannot be accessed.
for (arr, start..) |item, index|Explicit index range, open end; the index is start + j for the j-th iteration, not clamped to the iterable.
for (arr, start..end) |item, index|Closed index range; start/end are usize-compatible unsigned integers. Requires end - start == arr.len.
for (arr, 0..) |item|error[3000] explicit index range requires an index capture ('|item, index|').
for (arr, 0..2) |item, i| (len 3)error[3000] non-matching for loop lengths: the index range and the iterable differ in length (when both lengths are known).
for (0..5, 0..) |x, i|error[2000] expected ')' but found ',' — an explicit index range needs an array, slice, or pointer-to-array iterable.
assigning to |item| or |index|error[3002] cannot assign to immutable variable.
var scores: [4]i32 = .{ 10, 20, 30, 40 };
var values: i32 = 0;
for (scores) |v| values += v;                          // one capture

var weighted: i32 = 0;
for (scores) |v, idx| weighted += v * @intCast(i32, idx);

var rsum: i32 = 0;
for (0..4) |x| rsum += @intCast(i32, x);               // range iterable

var tail: i32 = 0;
for (scores, 1..) |v, idx| tail += v + @intCast(i32, idx);
var spanned: i32 = 0;
for (scores, 0..scores.len) |v, idx| spanned += @intCast(i32, idx);

The whole-loop excerpt above is from docs/sf/manuals/src/vol2/control.z98; the array, index, range, and explicit-index-range paths were compiled and run on the fixed compiler (rows for values 100 weighted 200, for range 6, for explicit 110 6). A slice iterable and a *[N]T iterable were each compiled and run separately (both sum 6); continue through a for step is pinned by repro/mi_matrix/stdlib_for_continue_xmod.

For a closed index range whose lengths are not known at compile time, mismatched lengths and an end below start are runtime traps under -fsafe rather than compile errors.

switch: prongs, ranges, and the mandatory else

switch (expr) { pattern => body, ... else => body, } matches one value against comma-separated items and ranges. The condition is a tagged union, an integer, an enum, or a boolean.

Case item Rule (measured)
literalInteger, character, and true/false literals.
enum memberShorthand (.Red) or qualified (Color.Red, shapes.Color.Red).
module constantA module-scope const integer, a module-qualified constant (mod.LO), an enum-member constant, or an alias chain; the initializer may be constant arithmetic.
range start...endInclusive; both bounds are compile-time constants of the condition's type.
range start..endExclusive; start included, end excluded.
enum rangeResolves by each member's underlying value, so enum(uN) gaps are exact.
var grade: i32 = 87;
var letter: i32 = 0;
switch (grade) {
    90...100 => letter = 65,      // inclusive
    80..90 => letter = 66,        // exclusive
    70..80 => letter = 67,
    else => letter = 70,          // mandatory
}

const LO: i32 = 100;
const HI: i32 = 102;
switch (pick) {
    LO...HI => slot = 7,          // module constants as bounds
    else => slot = 8,
}

const Color = enum { Red, Green, Blue };
switch (c) {
    Color.Red...Color.Green => r = 10,   // enum range, underlying values
    .Red... .Blue => r = 80,             // shorthand endpoints
    else => r = 20,
}

Ranges are compile-time and expand into sequential C case labels, so they cost nothing at runtime. Named constants and enum ranges are pinned by repro/mi_matrix/stdlib_switch_case_consts_xmod (rows include intrange 10 10 20, enexact 50 60, boolp 90 92) and repro/mi_matrix/stdlib_switch_enum_range_xmod (rows include incl 10 10 20, gaps 100 100 100); plain integer and character ranges are pinned by repro/mi_matrix/switch_case_range_xmod (130 47). Two boundaries are measured: a negative-valued named constant is not resolved, and a function-local const is not resolved by lowering; in both cases the item matches nothing and the value silently takes else.

The mandatory else

Every switch must spell an else prong, in statement and value position alike, even when the items cover the whole type. A switch without one, including the empty switch (x) {}, is level-0 error[3068] switch must have an 'else' prong at the switch node (rc 2, 0 .c). This is a deliberate divergence from official Zig, which accepts an exhaustive switch without an else. Because else is required, an exhaustive switch must still write one out. 

switch (x) {
    1 => r = 1,
}
// error[3068]: switch must have an 'else' prong

const Color = enum { Red, Green, Blue };
switch (color) {
    .Red => rgb = 1,
    .Green => rgb = 2,
    .Blue => rgb = 3,
    else => unreachable,          // reachable only if the value is wrong
}
// enum switch 3

A redundant else on an exhaustive switch is tolerated (switch (c) { .red, .green, .blue, else => ... } compiles and runs; Zig rejects it as an unreachable prong). unreachable is a live pal_trap(), not a no-op, under -fsafe and -ffast alike — write else => {} or a real fallback when the branch can run. The statement example above is from docs/sf/manuals/src/vol2/control.z98 (enum switch 3).

Prong captures and qualifiers

Shape Rule (measured)
tagged-union prong .m => |val| bodyBinds an immutable reference to the payload for that tag; shorthand and qualified spellings bind identically.
enum prong .red => |v| bodyBinds the switch operand (the enum value), matching Zig. An unused capture is accepted by Z98 (Zig rejects it).
else => |c| bodyerror[3001] switch else-prong capture (else => |capture|) is not supported.
capture on an integer prongNot bound; a use of the name rejects error[20] identifier '<x>' is not declared or imported in this module.
foreign qualifier (B.x on an A switch)error[3071] type mismatch in switch case item -- case item type may not be compatible with the switch condition type.
unknown member (Shape.bogus, .bogus)error[3071] no field or member function named '<x>' in union type (or ... in enum type); a related span notes the declaration.

The qualifier and member rejects are pinned by repro/mi_matrix/switch_case_qualifier_reject_xmod (12 primary error[3071] sites). The whole-union .tag switch form, its |c| ordinal capture, and payload rules are on the Unions page; the enum operand rules are on the Enums page.

Labels, break, and continue

A loop or a bare block can carry a label; a transfer names it to leave or advance an outer construct rather than the innermost one.

Form Rule (measured)
label: while ..., label: for ...A labeled loop; break :label/continue :label target it.
blk: { ... }A labeled block; a value-less break :blk; leaves it early. It is a statement, not a value producer.
breakExits the innermost while or for.
break :labelExits the matching loop or labeled block.
continueJumps to the next iteration of the innermost while or for (for a for, through its implicit step).
continue :labelJumps to the next iteration of the matching loop.
break :blk value;error[2000] expected ';' but found ... — a value-producing labeled block is not implemented.
duplicate labels in one functionAccepted; the compiler does not reject a duplicate, and a continue :outer binds the nearest label with that name. Keep labels unique by convention.
var pairs: i32 = 0;
outer: for (0..4) |a| {
    var b: i32 = 0;
    while (b < 3) : (b += 1) {
        if (b == 1) continue :outer;
        if (a == 2) break :outer;
        pairs += 1;
    }
}
// labeled 2

var found: bool = false;
lookup: {
    if (grade < 0) break :lookup;
    found = true;
}
// block true

A transfer inside defer/errdefer that leaves the body is rejected (error[3051] return, error[3052] break, error[3053] continue, error[3054] try); a target declared inside the body stays legal. See the Statements page. Labeled statements and their transfers are pinned by repro/mi_matrix/emission_labeled_ctrl_xmod (run on the fixed compiler as 3, 6, 10, 1 for a labeled block, a labeled while, a labeled switch-in-loop, and a literal break :blk).

Capture rules

Rule Measured
if/while capture conditions are optionals or error unions.A capture on any other condition is error[3058] capture condition must be an optional or error union type.
switch prong captures bind the condition's payload.A tagged-union prong binds the payload; an enum prong binds the operand; an else prong may not capture.
All captures are immutable.Assignment through an if/while/for/switch capture is error[3002] cannot assign to immutable variable.
A capture may not shadow or redeclare an enclosing name.error[3057] local declaration shadows an earlier declaration in an enclosing scope, with a note at the previous declaration.
_ discards a capture.A discarded name is not bound; it may be reused freely.
A capture is scoped to its construct.A while/for/switch capture is visible in the body or prong only. In the current compiler an if capture is also visible in the else arm; on the absent path that storage is undefined, so a use there reads garbage (the value varies, uninitialized; Zig rejects the use). Do not read an if capture in its else arm.

The shadow rejects are pinned by repro/mi_matrix/shadow_reject_xmod (one site per capture form, including if, while, for, and switch-prong captures). The for index capture, when present, is a separate immutable usize binding.
