Read Me

This is the manual for Z98: a small language that compiles to C89 and targets Pentium-class machines running Windows 95/98 or era Linux. The manual documents the compiler as it actually exists. It does not describe a hoped-for feature set, and it does not repeat a claim it cannot reproduce.

Reading paths

Nobody reads all six volumes cover to cover. Enter at the volume that matches your background and read forward:

  • Never programmed → I → II → III → IV/V as needed
  • Knows C, C++, Java, or Python → skim I → II → III → IV/V as needed
  • Knows modern Zig → II (for the differences) → III → IV/V
  • Wants to use it now → V → IV
  • Maintainer → VI → IV → the engineering docs
