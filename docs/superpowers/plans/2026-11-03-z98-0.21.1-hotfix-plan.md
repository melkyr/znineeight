**Interfaces:** shim signatures unchanged (`size_t strlen(const char*)`, `void* memcpy(void*,const void*,size_t)`, `void* memset(void*,int,size_t)`, `int strncmp(const char*,const char*,size_t)`).

- [ ] **Step 1: Harden the shims**

In the no-CRT shim writer, make every loop opaque to optimizer idiom conversion by using `volatile` pointers:
`volatile unsigned char* d = (volatile unsigned char*)dst;`
`const volatile unsigned char* s = (const volatile unsigned char*)src;`
`const volatile char* p = s;` (strlen/strncmp).
Bodies otherwise unchanged. This stops GCC `-ftree-loop-distribute-patterns`/`-foptimize-strlen` and MSVC idiom conversion from replacing the loop with a call to the shim itself.

- [ ] **Step 2: Regenerate the snapshot**

`bash scripts/gen_emit_support.sh <built-zig1>` then `bash scripts/check_emit_support.sh <built-zig1>` → 8/8. Edit only `emit_support.zig`; `sf/src/include/*` is generated.

### Task 3: z9play live console output + `--wav` progress

**Files:**
- Modify: `examples/z98/z9play/main.zig` (call `fflush(nullVoid())` directly after metadata/status/errors/final; `--wav` start + ~10 s progress lines)
- Modify: `sf/src/emit_support.zig` (no-CRT runtime: add a no-op `int fflush(FILE* stream)` shim in the `_WIN32 && ZIG_NO_CRT` block; the shim `fwrite` is unbuffered, so returning 0 is correct; keep the `FILE` type in scope)
- Regenerate: `sf/src/include/zig_runtime.c` / `zig_nocrt.c` via `scripts/gen_emit_support.sh`; `check_emit_support` 8/8

- [ ] **Step 1: Runtime shim (why)**

A direct `fflush` call is the only mechanism that reaches OWC/MSVC **static** CRTs (the operator's VM build); a runtime `GetModuleHandle("msvcrt.dll")` lookup silently no-ops there. The no-CRT link has no CRT, so provide the no-op shim; its `fwrite` already writes via `WriteFile` (unbuffered).

- [ ] **Step 2: Flush calls + `--wav` progress**

`fn flushOut() void { _ = fflush(nullVoid()); }` after the metadata line, each `writeStatus`, each `playFail` message, every `main` error message, and the final summary. `--wav`: print `wav: decoding <file>` + flush at start; every ~10 s print `wav: pos <mm:ss> frames=<n>` + flush; final line unchanged.

- [ ] **Step 3: Verify**

`check_emit_support` 8/8; rebuild; MinGW **CRT and no-CRT** Wine `--wav` runs rc=0 with unchanged frames/WAV; live-flush `timeout 3` probe prints `wav: decoding` before being killed; `--info`/interactive/no-audio rc unchanged; `tier_win9x` 16/16; 8 pins unmoved; `git diff --check`.

- [ ] **Step 4: Commit**

`git commit -m "fix(z9play): call fflush directly; add a no-CRT fflush shim (Win9x)"`
