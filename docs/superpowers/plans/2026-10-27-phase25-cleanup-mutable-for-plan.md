## Review Focus

1. **`|*x|` over a `[]const T` iterable** — capture must be `*const T`; `x.* = v` / `x.f = v` must error. C drops `const`, so sema is the only enforcement. Test: Task 3 sema negative fixture + Task 4 e2e.
2. **`for (0..n) |*i|`** — must be rejected with a clear diagnostic (a range has no addressable element). Test: Task 3 negative fixture.
3. **`|*x|` over a `*[N]T` (ptr-to-array)** — capture is a row pointer `*[M]T`. The lowerer already casts ptr-to-array to an element pointer (`fa_ep`), so the address form is **`decay=2` (`&base[idx]`)**, not `decay=1` (which would be `&(*base)[idx]` on an already-element base and is wrong after the cast). Test: Task 4 e2e fixture.
4. **Builtin name-table drift** — adding a builtin to one table but not the others must fail a gate (intern-id shifts move pins). Test: Task 1 `gate_builtin_names.sh`.
5. **Delivery-scan TEMP_NONE** — a void result delivered into a fixed-arity machine slot must panic, not silently swap operands. Test: Task 1 guard + full corpus run.
