# z9play M0 — OGG container + Vorbis headers + `--info` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Parse the OGG container (pages, segment tables, packet reassembly) and the Vorbis **identification** and **comment** headers, and expose them via `z9play --info <file.ogg>` (sample rate, channels, duration, tags).

**Architecture:** A new example at `examples/z98/z9play/`. `ogg.zig` owns the container (page framing → a packet iterator). `vorbis_info.zig` parses the id + comment headers. `main.zig`/`cli.zig` implement only the `--info` subset of the eventual CLI. No audio, no math, no decoder — this milestone is pure byte parsing, so it needs neither `std_math` nor the audio layer.

**Tech Stack:** Z98 (`zig1` → C89, `gcc -m32`, `-fsafe`), `std_file`, `std_mem`, `std_str`, `std_buf`, `std.io.print`; fixtures generated by `vorbis-tools` (`oggenc`/`ogginfo`) acquired without root.

**Spec:** `docs/superpowers/specs/2026-10-11-z9play-ogg-player-design.md` (binding).

**Sequence:** FIRST milestone of z9play. NEXT: `2026-10-11-z9play-m1-setup-codebooks-plan.md`.

### Task 1: OGG container (`ogg.zig`)

**Files:** Create `examples/z98/z9play/ogg.zig`; Create `examples/z98/z9play/tests/ogg_test.zig` (unit harness).

**Interfaces:**
- Produces:
  - `pub const Page = struct { granule: u64, serial: u32, seq: u32, header_type: u8, body_start: u32, body_len: u32 };`
  - `pub const Packet = struct { bytes: []const u8 };` (reassembled, contiguous copy in a caller arena)
  - `pub const OggError = error{ BadCapture, BadVersion, Truncated, Crc, OutOfMemory };`
  - `pub fn pageAt(data: []const u8, off: usize) OggError!Page` (parses the page header at `off`; `body_start`/`body_len` derived from the segment table).
  - `pub fn nextPage(data: []const u8, page: Page) usize` (offset of the next page).
  - `pub fn isCompletePacket(page: Page) bool` (continuation/end flags).
  - `pub fn crcOk(data: []const u8, page: Page) bool` (CRC-32 over the page with the CRC field zeroed) — CRC via `std_crypto` CRC-32 if suitable, else a local table.
  - A packet reassembler: `pub fn reassemble(arena, data) OggError![]Packet` per logical stream (accumulates segment bodies until a segment `< 255` terminates a packet; handles pages split across packets).

- [ ] **Step 1: Write the failing unit test** `tests/ogg_test.zig`: page count + first/last granule for `testdata/sine_stereo_44100.ogg`; that reassembly yields the three Vorbis headers as the first packets (packet 0 begins `\x01vorbis`, packet 1 `\x03vorbis`, packet 2 `\x05vorbis`).
- [ ] **Step 2: Run it** (`-fsafe`) — expect FAIL (not implemented).
- [ ] **Step 3: Implement `ogg.zig`** (page header 27 bytes + segment table; little-endian fields; CRC verify; reassembly).
- [ ] **Step 4: Run the test** — expect PASS.
- [ ] **Step 5: Commit** `example(z9play): OGG container page parse + packet reassembly`.

**Gate:** unit test PASS under `-fsafe`; CRC verify true on all fixture pages; re-run deterministic.
