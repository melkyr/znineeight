## Deviations / concerns

1. **Crosscheck driver-name compatibility.** The Task 1 harness discovers
   modules from `scripts/stdlib/ref/<module>/` and looked for
   `stdlib_<module>_cross_xmod` / `stdlib_cross_<module>_xmod`. Task 2's
   binding paths are `ref/std_rand` and `stdlib_rand_cross_xmod`, which do
   not match either spelling. I added a fallback in
   `scripts/stdlib/run_crosscheck.sh::driver_dir_for` that also tries the
   module name with a leading `std_` stripped (only when the exact names are
   absent). Without it the crosscheck reports `MISSING-DRIVER`. This is the
   only Task 1 script touched; the four explicit Task 2 paths are unchanged.
2. **"1M" interpretation.** The stat fixture uses 2^20 = 1,048,576 u32s so
   the binding 256-bin expectation is exactly 16384/bin (as stated in the
   context); literal 1,000,000 draws would give 15625/bin.
3. No compiler defects were observed. No push, no `run.err` change, no
   `progress.md` edit.
