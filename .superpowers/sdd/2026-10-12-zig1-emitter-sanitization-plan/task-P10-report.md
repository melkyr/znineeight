### 4. Behavior-delta analysis (why the unified rule is exactly this predicate)

The two old addr predicates disagree ONLY on `(base-node kind, base-temp kind) = (not-array, ptr-to-array)` ("(0,1)"): `lowerLValueAddr`'s AND-gate (`la_c0_is_array && tempTypeIsPtrToArray`) takes `BIN_ADD`, `lowerFieldStore`'s temp-only gate takes `load_index`. Language semantics (spec §1.2: `*[N]T` indexing is auto-deref ELEMENT access; slice/`[*]` indexing is row-granular) decide each sub-case:

- (0,1) genuine `*[N]T` (`&pp[i]` / `pp[i].field = v`): element of the pointee → `load_index{decay=1}` (`&(*pp)[idx]`) is right.
